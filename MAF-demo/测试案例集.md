# Workflow编排系统 - 测试案例集

## 🧪 测试场景设计

按照不同复杂度和业务场景，覆盖5种编排模式的全面测试。

---

## 场景1: 简单查询（条件路由）

### 测试用例1.1: 单专家触发
```json
{
  "input": "现在几点了？",
  "workflowType": "ConditionalRouting"
}
```

**预期行为**:
- Router判断: `needsTimeInfo = true`
- 激活Agent: TimeExpert
- 执行时间: < 3秒

---

### 测试用例1.2: 双专家触发
```json
{
  "input": "明天北京的天气怎么样？适合出行吗？建议几点出发？",
  "workflowType": "ConditionalRouting",
  "enableCheckpoint": true
}
```

**预期行为**:
- Router判断: `needsWeather = true, needsTimeInfo = true`
- 激活Agent: WeatherAdvisor + TimeExpert（并行）
- 执行时间: 3-5秒
- Checkpoint: 应保存到数据库

---

### 测试用例1.3: 三专家触发
```json
{
  "input": "帮我分析：当前时间、北京天气、计算 25*40 的结果",
  "workflowType": "ConditionalRouting"
}
```

**预期行为**:
- Router判断: `needsTimeInfo = true, needsWeather = true, needsDataAnalysis = true`
- 激活Agent: TimeExpert + WeatherAdvisor + DataAnalyst（并行）
- 执行时间: 4-6秒

---

## 场景2: 全面分析（FanOut/FanIn）

### 测试用例2.1: 多维度分析
```json
{
  "input": "全面分析：当前时间？北京天气？上海天气？2+3*4的结果？",
  "workflowType": "FanOutFanIn"
}
```

**预期行为**:
- 4个专家并行执行（DataAnalyst, TimeExpert, WeatherAdvisor, Developer）
- Aggregator自动汇总4条消息
- Coordinator给出综合答案
- 执行时间: 5-8秒

---

### 测试用例2.2: 对比分析
```json
{
  "input": "对比分析北京和上海的天气差异，并评估哪个城市更适合出行",
  "workflowType": "FanOutFanIn"
}
```

**预期行为**:
- 所有专家提供多角度见解
- 最终答案应包含多个维度的对比

## 场景3: 规划执行（顺序链）

### 测试用例3.1: 学习计划
```json
{
  "input": "制定一个为期3个月的Python学习计划，并评估这个计划的可行性",
```

**预期行为**:
1. Planner: 输出详细的学习计划（分步骤）
2. Executor: 按计划执行（可能调用工具）
3. Reviewer: 审核并提出改进建议
- 执行时间: 8-12秒

---

- Planner生成方案框架

## 场景4: 复杂任务（混合编排）

### 测试用例4.1: 项目开发规划

## 场景7: Checkpoint恢复

### 测试用例7.1: 长时间任务暂停恢复
```json
// 第1步: 启动任务（启用Checkpoint）
POST /api/workflow/hybrid-orchestration
{
  "input": "设计一个复杂的微服务架构...",
  "enableCheckpoint": true
}

// 响应获取 workflowId: "workflow-abc123"

// 第2步: 查询状态
GET /api/workflow/status/workflow-abc123

// 第3步: 恢复执行（如果中断）
POST /api/workflow/resume/workflow-abc123
```

**预期行为**:
- Checkpoint数据保存到数据库 `AI_Agent_Workflow.ExecutionContext`
- 恢复时从上次中断点继续执行

### 自动化测试脚本（Python）
```python
import requests
import json

BASE_URL = "http://localhost:5000"

def test_conditional_routing():
    response = requests.post(
        f"{BASE_URL}/api/workflow/conditional-routing",
        json={"input": "北京天气如何？"}
    )
    result = response.json()
    
    assert result["status"] == "Completed"
    assert result["workflowType"] == "ConditionalRouting"
    assert result["executionTimeMs"] < 10000
    print("✓ 条件路由测试通过")

def test_fanout_fanin():
    response = requests.post(
        f"{BASE_URL}/api/workflow/fanout-fanin",
        json={"input": "全面分析当前状况"}
    )
    result = response.json()
    
    assert result["status"] == "Completed"
    assert len(result["stepsExecuted"]) >= 3
    print("✓ FanOut/FanIn测试通过")

if __name__ == "__main__":
    test_conditional_routing()
    test_fanout_fanin()
    print("\n所有测试通过！")
```
